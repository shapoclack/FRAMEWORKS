О проекте: Учёт курсовых работ

Проект представляет собой специализированную информационную систему для автоматизации учебного процесса кафедры в части распределения и контроля выполнения курсовых проектов.

Цель и назначение

Система решает проблему координации между студентами, научными руководителями и учебно-методическим отделом кафедры. Обеспечивается прозрачный выбор тем, фиксация сроков сдачи (дедлайнов) и аудит изменения статусов.

Целевая аудитория

Студенты

Поиск свободных тем по ключевым словам, закрепление за научным руководителем, отслеживание статуса сдачи.

Руководители

Формирование каталога тем, проверка работ, изменение статусов («на проверке» → «защищена»), контроль нагрузки.

Методисты

Сводная статистика по группам, выявление нераспределённых студентов, соблюдение лимитов нагрузки преподавателей.

Сущности предметной области (ПР3)

  • Студент (Student): ФИО, учебная группа, направление подготовки, e-mail.
    Таблица students
  • Научный руководитель (Supervisor): ФИО, степень, должность, e-mail, максимальный лимит тем (1..20).
    Таблица supervisors
  • Тема (Topic): Название, описание, руководитель, закрепленный студент, статус, дедлайн.
    Таблица topics
  • История статусов (StatusHistory): Аудит смены статусов (старый статус, новый статус, дата, автор).
    Таблица status_history

Архитектура и стек технологий

Python 3.13 Django 6.1 (MVT) Bootstrap 5.3 SQLite / PostgreSQL Pytest Git / PR5

Приложение построено по архитектурному шаблону MVT (Model-View-Template): модели инкапсулируют логику работы с базой данных через Django ORM, представления (views) обрабатывают HTTP-запросы и возвращают сформированные HTTP-ответы, а шаблоны (templates) на основе Bootstrap формируют адаптивный веб-интерфейс.
