### 4. Доработка индивидуального проекта

#### 4.1. Спроектированная структура базы данных и ключи
Создан файл базы данных `data/coursework.sqlite`. В скрипте `sql/schema.sql` описаны следующие таблицы:
1. **`students`** — реестр студентов:
   * `id` (`INTEGER PRIMARY KEY`) — уникальный идентификатор;
   * `full_name` (`TEXT NOT NULL`), `group_name` (`TEXT NOT NULL`), `direction` (`TEXT`), `email` (`TEXT NOT NULL UNIQUE`), `created_at` (`TEXT NOT NULL DEFAULT (datetime('now'))`).
2. **`supervisors`** — преподаватели и научные руководители:
   * `id` (`INTEGER PRIMARY KEY`);
   * `full_name` (`TEXT NOT NULL`), `degree` (`TEXT`), `position` (`TEXT`), `email` (`TEXT NOT NULL UNIQUE`);
   * `max_topics` (`INTEGER NOT NULL DEFAULT 5 CHECK (max_topics BETWEEN 1 AND 20)`).
3. **`topics`** — темы курсовых работ:
   * `id` (`INTEGER PRIMARY KEY`);
   * `title` (`TEXT NOT NULL`), `description` (`TEXT`), `deadline` (`TEXT`), `created_at` (`TEXT`);
   * `supervisor_id` (`INTEGER NOT NULL, FOREIGN KEY REFERENCES supervisors(id) ON DELETE RESTRICT`);
   * `student_id` (`INTEGER, FOREIGN KEY REFERENCES students(id) ON DELETE SET NULL`);
   * `status` (`TEXT NOT NULL DEFAULT 'свободна' CHECK (status IN ('свободна', 'закреплена', 'на проверке', 'защищена'))`).
4. **`status_history`** — аудит смены статусов:
   * `id` (`INTEGER PRIMARY KEY AUTOINCREMENT`), `topic_id` (`INTEGER NOT NULL, FOREIGN KEY REFERENCES topics(id) ON DELETE CASCADE`), `old_status`, `new_status`, `changed_at`, `changed_by`.

#### 4.2. Модули Python для работы с БД
* **`db/database.py`:** функция `get_connection()` возвращает объект подключения `sqlite3.connect()`, в котором гарантированно включен контроль внешних ключей командой `PRAGMA foreign_keys = ON;`.
* **`db/import_json.py`:** скрипт загрузки данных из JSON-файлов каталога `data/` (`students.json`, `supervisors.json`, `topics.json`). Таблицы заполняются методом `conn.executemany()` с параметрами `?`. Применена транзакция `conn.commit()` / `conn.rollback()`. Скрипт учитывает иерархию внешних ключей (руководители и студенты вставляются перед темами).

#### 4.3. Каталог SQL-запросов (`sql/queries.sql`)
Разработано и сохранено **17 SQL-запросов** с подробными комментариями (не менее двух запросов каждого вида):
* *Выборка и сортировка:* получение тем курсовых (`ORDER BY`), список руководителей, пагинация студентов (`LIMIT 5 OFFSET 0`);
* *Фильтрация WHERE:* поиск свободных тем (`WHERE status = 'свободна'`), контекстный поиск (`LIKE`), дедлайн в интервале (`BETWEEN`), студенты без тем (подзапрос `WHERE id NOT IN (SELECT student_id ...)`);
* *Соединение таблиц JOIN:* полная информация о теме (`topics` + `supervisors` + `students`), темы в работе (`JOIN ... WHERE status IN ('закреплена', 'на проверке')`), свободные темы преподавателя;
* *Агрегатные функции:* общее число тем и суммы по статусам (`COUNT(*)`, `SUM(CASE WHEN ...)`), показатели по лимитам нагрузки (`AVG`, `MIN`, `MAX`);
* *Группировка GROUP BY:* распределение тем по руководителям (`LEFT JOIN + GROUP BY`), распределение тем по статусам, студентов по группам;
* *Фильтрация групп HAVING:* преподаватели с более чем 1 темой (`HAVING COUNT(t.id) > 1`), группы с числом студентов более 1.

#### 4.4. Интеграция с Django и веб-страницы
В `coursework/views.py` и `core/views.py` данные запрашиваются из SQLite напрямую. Использована фабрика строк `conn.row_factory = sqlite3.Row`, что позволило обращаться к атрибутам по именам колонок. Все пользовательские фильтры передаются параметрами `?`. Реализованы страницы:
* `/coursework/topics/` — каталог всех тем с поиском и фильтрацией;
* `/coursework/active/` — темы в процессе выполнения (результат соединения трёх таблиц через `JOIN`);
* `/coursework/available/` — поиск свободных тем по дате дедлайна и ключевым словам (`NOT IN`, форма GET);
* `/coursework/statistics/` — аналитика (`COUNT`, `GROUP BY`, `HAVING`);
* `/coursework/supervisors/` и `/coursework/students/` — реестры руководителей и студентов;
* `/coursework/topics/<id>/` — детальная карточка темы и аудит;
* Навигация сайта оформлена в `templates/base.html` через именованные URL Django (`{% url %}`).
