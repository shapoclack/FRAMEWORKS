# Система учета тем курсовых работ

## Назначение
Приложение предназначено для учета и распределения тем курсовых работ
между студентами и научными руководителями. Позволяет проверять
доступность темы, закреплять её за студентом и отслеживать статус работы.

## Целевая аудитория
- студенты;
- преподаватели (научные руководители);
- сотрудники кафедры (методисты).

## Предметная область
Учебный процесс в высшем учебном заведении: учет курсовых работ,
их тем, руководителей и статусов выполнения.

## Основные сущности
- Студент
- Тема
- Руководитель
- Статус

## Основные функции
- проверка доступности темы для закрепления;
- закрепление темы за студентом;
- смена статуса темы (свободна → закреплена → на проверке → защищена);
- вывод информации о теме, студенте и руководителе.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
