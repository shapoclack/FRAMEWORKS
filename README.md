# Система учета тем курсовых работ

## Назначение
Приложение предназначено для учета и распределения тем курсовых работ
между студентами и научными руководителями. Позволяет проверять
доступность темы, закреплять её за студентом и отслеживать статус работы.

## Целевая аудитория
- студенты;
- преподаватели (научные руководители);
- сотрудники кафедры (методисты).

## Предметная область
Учебный процесс в высшем учебном заведении: учет курсовых работ,
их тем, руководителей и статусов выполнения.

## Основные сущности
- Студент
- Тема
- Руководитель
- Статус

## Основные функции
- проверка доступности темы для закрепления;
- закрепление темы за студентом;
- смена статуса темы (свободна → закреплена → на проверке → защищена);
- вывод информации о теме, студенте и руководителе.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
# Система учета тем курсовых работ

Консольное приложение для учета, поиска и распределения тем курсовых работ
между студентами и научными руководителями.

## Возможности

- просмотр списка тем;
- поиск тем по названию;
- фильтрация свободных тем;
- сортировка тем по названию;
- добавление новых тем;
- закрепление темы за студентом и освобождение темы;
- изменение статуса темы (свободна → закреплена → на проверке → защищена);
- статистика по статусам;
- добавление студентов и руководителей;
- сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска, меню и сценарии;
- `topics.py` — работа с темами;
- `students.py` — работа со студентами;
- `supervisors.py` — работа с руководителями и закрепление тем;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции (ввод, генерация id);
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

## Формат хранения данных

Данные хранятся в JSON-файлах в каталоге `data/`:

- `topics.json` — список тем;
- `students.json` — список студентов;
- `supervisors.json` — список руководителей.

Каждая запись — словарь с полями `id` и профильными полями
(`title`, `full_name`, `group`, `status` и т. д.).
